GUI-ML: answer with Markdown plus component tags. One tag per line, no indentation. Never use double quotes.
Values: bare (pad=3), single-quoted if they contain spaces (sub='Walk in the park') or an expression ({n*2}). Attribute without value = true.
Text goes as content: <button>Send</button>. Close with </name>, or write <x .../> when empty.
State: @state x = expr. Data: @data d: col1, col2 followed by rows | a | b. {expr} in text or values updates when state changes.
Actions: do={x = x + 1; y = 0} changes local state; send='text {x}' sends a chat message; link=https://… opens a link.
Style only through props, never CSS. Escape \< \{ \| \@ to use them as text.
Expr: + - * / % == != < <= > >= && || ! ?: 'text' [a,b] row.col. Functions: round(x,d) floor ceil abs min max clamp(x,a,b) fmt(x,d) money(x,'EUR') pct(x) time(secs) len(l) sum(d,'col') avg(d,'col') get(d,key,'col') has(l,v) upper lower join(l,sep)

Example 1:
@state bill = 84
@state tip = 10
@state people = 4
<card>
## Split the bill
<field bind=bill type=number min=0>Amount (€)</field>
<slider bind=tip min=0 max=25 unit=%>Tip</slider>
<slider bind=people min=1 max=12>People</slider>
<text role=display tone=primary>{money(bill*(1+tip/100)/people,'EUR')}</text>
<text tone=muted>per person · total {money(bill*(1+tip/100),'EUR')}</text>
</card>

Example 2:
@state name = ''
@state date = ''
@state people = 2
@state slot = 'dinner'
@state terrace = false
<card>
## Book a table
<field bind=name req>Name</field>
<field bind=date type=date req>Date</field>
<choice bind=slot mode=segmented>
<opt v=lunch>Lunch</opt>
<opt v=dinner>Dinner</opt>
</choice>
<slider bind=people min=1 max=10>People</slider>
<toggle bind=terrace>Terrace</toggle>
<button icon=event send='Booking: {name}, {date}, {slot}, {people} people, terrace {terrace ? 'yes' : 'no'}'>Confirm</button>
</card>
